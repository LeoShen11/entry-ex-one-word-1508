My ex in one word: **Discontinued** — a product line quietly pulled from the shelves, no recall notice, no replacement, just gone from the catalogue.

## Run it

```sh
python3 main.py
```

The program validates the word (exactly one word, 1–111 characters, nothing else) and writes it to `/output/entry.txt`, then reads the file back and checks it matches byte for byte.
